## Typography: Space Grotesk + Space Mono

- **Display and body:** Space Grotesk
- **Mono:** Space Mono for evidence IDs, conditions, commands, counts and code

The fonts are wired through `next/font/google` in `apps/web/app/layout.tsx`. `--font-space-grotesk` and `--font-space-mono` are mapped to Tailwind's `--font-sans` and `--font-mono` tokens.

## Gradients

Two gradients are derived from Amber Monitor. Use no more than one on a screen.

### Background gradient

```css
/* Light */
--gradient-bg: linear-gradient(135deg, oklch(0.98 0.01 70) 0%, oklch(0.95 0.015 85) 100%);

/* Dark */
--gradient-bg: linear-gradient(135deg, oklch(0.14 0.01 70) 0%, oklch(0.17 0.015 85) 100%);
```

Use for a hero or large empty field. It should remain peripheral and nearly invisible.

### Accent gradient

```css
/* Light */
--gradient-accent: linear-gradient(to right, oklch(0.5 0.15 70) 0%, oklch(0.52 0.14 90) 100%);

/* Dark */
--gradient-accent: linear-gradient(to right, oklch(0.78 0.15 70) 0%, oklch(0.8 0.14 90) 100%);
```

Use for a primary hero action, a selected evidence border or one data accent bar. Do not place body text over it. Tailwind exposes `bg-brand-bg` and `bg-brand-accent`.

The background midpoint retains 17.01:1 contrast in light mode and 17.39:1 in dark mode. A short label on the accent midpoint retains 5.49:1 in light mode and 10.49:1 in dark mode.

## Tone and voice

### Words to use

Be direct, specific, number-forward and factual. Prefer verbs over adjectives. Use terms such as reproduced, observed, matched, valid run, clean control, evidence, bounded and requires approval.

### Words to avoid

Avoid hype such as revolutionary, game-changing, unleash and supercharge. Do not say fixed, proven or guaranteed until the evidence supports that conclusion. Avoid simply, easy, seamless and unlock.

### Voice example

> Reproduced in 10 of 10 valid runs. Clean control passed once. Draft PR requires approval.

## Usage dos and don'ts

**Do:**

- Use semantic CSS variables rather than hardcoded colors in components.
- Keep the 4 px spacing grid and Verdict's sharp 2 px geometry.
- Respect system color preference and test every component in both modes.
- Use mono type for evidence IDs, environment values, commands and changing counts.
- Reserve amber for selection, focus and primary action.
- Use green or red only for verified semantic outcomes.

**Don't:**

- Add another decorative accent color.
- Use `transition: all`; name the changed property.
- Mix both gradients on one screen or animate a gradient.
- Put body text on the accent gradient.
- Use rounded card grids, generic SaaS claims or fake product screenshots.
- Call an issue reproduced before the observation threshold passes.
